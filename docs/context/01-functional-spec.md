## 2. F-001 토스 로그인

토스 SDK를 활용하여 별도 회원가입 없이 간편하게 로그인하고, 사용자를 식별하여 DB의 사용자 데이터와 연결한다.

### 2.1 기능 흐름

| 단계 | 액션 | 시스템 동작 |
| --- | --- | --- |
| 1 | 앱 진입 | 스플래시 화면 표시 후 로그인 화면으로 이동 |
| 2 | 토스 로그인 버튼 클릭 | 토스 SDK 인증 화면 호출 |
| 3 | 토스 앱 인증 | 사용자가 토스 앱에서 인증 완료 |
| 4 | 인증 성공 | 사용자 식별자 확보 → users 테이블 조회/등록 → 메인 화면 이동 |
| 5 | 인증 실패 | 오류 메시지 표시 후 로그인 화면 유지 |

### 2.2 예외 처리

| 코드 | 원인 | 처리 방법 |
| --- | --- | --- |
| F-001-E1 | 토스 앱 미설치 | 토스 앱 설치 유도 팝업 표시 |
| F-001-E2 | 네트워크 오류 | '네트워크를 확인해주세요' 메시지 표시 |
| F-001-E3 | 인증 취소 | 로그인 화면으로 복귀 |

## 3. F-002 바코드 스캔

카메라를 이용해 상품 바코드(JAN)를 인식하고 코드 번호를 추출한다.

> 디코딩 엔진
> 
> - 카메라/스캔: React Native 네이티브 바코드 디코더 (iOS Vision / Android ML Kit 기반)
> - 후보 라이브러리: `expo-camera`(Expo) 또는 `react-native-vision-camera`(공통)

### 3.1 기능 흐름

| 단계 | 액션 | 시스템 동작 |
| --- | --- | --- |
| 1 | 스캔 버튼 클릭 | 카메라 권한 확인 팝업 표시 |
| 2 | 카메라 권한 허용 | 스캔 화면 실행 |
| 3 | 카메라 화면 표시 | 가이드 프레임과 함께 실시간 카메라 화면 표시 |
| 4 | 바코드 감지 | 네이티브 바코드 디코더(iOS Vision / Android ML Kit)로 코드 자동 인식 |
| 4-1 | 인식 실패 | 일정 시간 미인식 시 가이드 표시("각도·조명 조정") 후 재시도 |
| 4-2 | 반복 실패 | 직접 입력(6단계)으로 유도 |
| 5 | 인식 성공 | Toast로 성공 메시지 띄운 후 상품 정보 조회(F-003)로 이동 |
| 6 | 직접 입력 버튼 | 카메라 대신 바코드 번호 직접 입력 가능 |

### 3.2 지원 코드 형식

| 코드 형식 | 설명 | 사용 예 |
| --- | --- | --- |
| JAN-13 | 일본 표준 상품 코드 (EAN-13) | 일본 마트·편의점 식품, 일용품 |
| JAN-8 | 소형 상품용 단축 코드 (EAN-8) | 소형 과자류, 음료 |

### 3.3 예외 처리

| 코드 | 원인 | 처리 방법 |
| --- | --- | --- |
| F-002-E1 | 카메라 권한 거부 | '카메라 권한이 필요합니다' 안내 후 설정 화면 이동 유도 |
| F-002-E2 | 인식 불가 | 일정 시간 이상 미인식 시 '직접 입력' 유도 메시지 표시 |
| F-002-E3 | (JAN-13/JAN-8)외 다른 코드 | '인식할 수 없는 바코드입니다' 메시지 표시 |

## 4. F-003 상품 정보 조회

 F-002 단계에서 스캔된 바코드 번호로 라쿠텐에서 조회하고,  실패 시 촬영 사진에서 상품명을 추출해 재조회하며, 그래도 없으면 사진을 AI가 직접 분석한 뒤 한국어로 번역·표시한다.

> 동일 바코드 재조회 시 캐시를 우선 확인하여 외부 API·AI 호출을 줄인다. (Gemini 분당 15회 제한 및 라쿠텐 레이트리밋 대응)
> 

### 4.1 기능 흐름

| 단계 | 액션 | 시스템 동작 |
| --- | --- | --- |
| 1 | 바코드 번호 수신 | F-002에서 전달받은 코드로 조회 시작 (캐시 우선 확인) |
| 2 | 라쿠텐 API 호출 | JAN 코드로 라쿠텐 상품검색 API 호출 → 라쿠텐 제품검색 API의 productCode 파라미터에 JAN 입력하여 호출 |
| 3 | 결과 있음 | 상품 정보 파싱 → 7단계(한국어 분석)로 |
| 4 | 결과 없음/실패 | '상품을 찾을 수 없습니다. 제품 전면을 촬영해주세요' 안내 후 카메라 전환 |
| 5 | 제품 직접 촬영 | 사용자가 상품명·브랜드가 보이는 전면 촬영 |
| 6 | 상품명 추출 → 라쿠텐 재 조회 | Gemini로 사진에서 상품명·브랜드 추출 → 그 키워드로 라쿠텐 재검색 |
| 6-1 | 재조회 성공 | 라쿠텐 상품 정보 확보 → 7단계로 |
| 6-2 | 재조회 실패 | 사진 자체를 Gemini로 직접 분석하여 상품 정보 추출 |
| 7 | 한국어 분석·번역 | 확보된 상품 정보를 Gemini가 한국어로 번역 후 표시 |

우리가 사용할 라쿠텐 공식 API 설명서 링크

### 4.2 조회 결과 표시 항목

| 항목 | 출처 | 비고 |
| --- | --- | --- |
| 상품명 (일본어) | API | 원문 그대로 표시 |
| 상품명 (한국어) | AI 번역 | Gemini가 번역하여 함께 표시 |
| 가격 | API | 엔화(¥) 표시("라쿠텐 참고가 ¥ (현지 매장가와 다를 수 있음) |
| 상품 이미지 | API / 직접 촬영 | API 없을 경우 사용자 촬영 이미지 사용 |
| 상품 설명 | 라쿠텐 사이트에 있는 상품 설명 | F-003 결과 |

### 4.3 예외 처리

| 코드 | 원인 | 처리 방법 |
| --- | --- | --- |
| F-003-E1 | 라쿠텐 API 타임아웃 | 5초 초과 시 사진 촬영 후 재조회 흐름으로 전환 |
| F-003-E2 | 라쿠텐 429 (한도 초과) | 캐시 활용, 사용자에게 잠시 후 재시도 안내 |
| F-003-E3 | 네트워크 없음 | '인터넷 연결을 확인해주세요' 메시지 표시 |
| F-003-E4 | 사진에서 상품명 추출 실패 | Gemini가 상품명·브랜드를 못 찾을 경우 '상품명이 잘 보이게 다시 촬영해주세요' 안내 |
| F-003-E5 | 재조회 결과 없음 | 추출 키워드로도 라쿠텐 미검색 시 사진 직접 분석으로 전환 |
| F-003-E6 | 촬영 이미지 분석 실패 | '이미지를 인식할 수 없습니다. 다시 촬영해주세요' 안내, 반복 실패 시 상품명 직접 입력 유도 |
| F-003-E7 | Gemini API 한도 초과 (분당 15회) | 호출 대기열 처리 또는 '잠시 후 다시 시도해주세요' 안내 |

## 5. F-004 상품 저장 (위시리스트)

AI 분석이 완료된 상품을 Supabase DB에 저장하여 나중에 다시 확인할 수 있다. (사용자별 저장)

### 5.1 기능 흐름

| 단계 | 액션 | 시스템 동작 |
| --- | --- | --- |
| 1 | 분석 결과 화면 표시 | F-003 분석 완료 후 결과 화면 하단에 저장 버튼 표시 |
| 2 | 저장 버튼 클릭 | 상품 정보를 saved_products 테이블에 저장 (user_id 연결) |
| 3 | 저장 완료 | '저장되었습니다' 토스트 표시, 버튼 상태 '저장됨'으로 변경 |
| 4 | 중복 저장 시도 | (user_id + barcode 중복) '이미 저장된 상품입니다' 안내 후 목록 이동 버튼 표시 |

### 5.2 저장 데이터 항목 (saved_products)

| 항목 | 설명 |
| --- | --- |
| 상품명 (일본어/한국어) | API 또는 AI 번역 결과 |
| 상품 설명 | API 또는 AI 번역 결과 |
| 바코드(JAN) | JAN 코드 (재조회로 확보, 끝까지 미확보 시 NULL) |
| 상품 이미지 URL | API 이미지 또는 촬영 이미지 |
| 가격 / 통화 | 가격 및 통화(기본 JPY) |
| 국가 | 국가코드 (기본 JP, 확장 대비) |
| 저장 일시 | 타임스탬프 |
| 데이터 출처 | API 조회 / 사진 분석 — 어느 경로로 저장됐는지 구분 |

### 5.3 예외 처리

| 코드 | 원인 | 처리 방법 |
| --- | --- | --- |
| F-004-E1 | DB 저장 실패 | '저장에 실패했습니다. 다시 시도해주세요' 메시지 표시 |
| F-004-E2 | 네트워크 오류 | '네트워크를 확인해주세요' 안내 |

## 7. F-006 공유하기

상품 정보를 외부 앱으로 공유하거나 링크를 복사할 수 있다.

### 7.1 기능 흐름

| 단계 | 액션 | 시스템 동작 |
| --- | --- | --- |
| 1 | 공유 버튼 클릭 | 분석 결과 화면의 공유 아이콘 클릭 |
| 2 | 공유 방식 선택 | 공유 시트 표시 (텍스트 복사 / 이미지로 저장) |
| 3 | 텍스트로 복사 | 상품명(한/일) + 한 줄 요약 + 가격 + 앱 출처를 클립보드에 복사, '복사되었습니다' 토스트 |
| 4 | 이미지로 저장 | 분석 결과 화면을 이미지로 캡처하여 저장 |
| 4-1 | (예외) 저장 권한 거부 | '사진 저장 권한이 필요합니다' 안내 후 설정 유도 |

복사 텍스트 예시:

```
[삑] 호로요이 복숭아맛 (ほろよい もも) / 알코올 3% 복숭아맛 츄하이 / 약 ¥150 — 삑으로 스캔한 상품 정보
```

*토스트:**Toast)** 는 화면에 **잠깐 떴다가 자동으로 사라지는 작은 알림 메시지**예요. 식빵이 토스터에서 톡 튀어나왔다가 사라지는 모습 같다고 해서 붙은 이름이에요.

### 7.2 예외 처리

| 코드 | 원인 | 처리 방법 |
| --- | --- | --- |
| F-006-E1 | 클립보드 복사 실패 | '복사에 실패했습니다' 메시지 표시 |
| F-006-E2 | 이미지 저장 실패 | '이미지 저장에 실패했습니다' 메시지 표시 |
| F-006-E3 | 사진 저장 권한 거부 | '사진 저장 권한이 필요합니다' 안내 후 설정 이동 유도 |

## 8. API 리스트

| 번호 | API명 | 용도 | 비고 | 무료여부 | 구분 |
| --- | --- | --- | --- | --- | --- |
| 1 | 라쿠텐 제품검색 API (Product Search) | 상품 정보 조회 | JAN을 productCode로 조회, applicationId 인증 | 무료 | 조회 |
| 2 | Gemini API | 한국어 요약·번역, 이미지 분석 | Google AI Studio 무료 플랜, 분당 15회 제한 | 무료 | AI |

| 4 | Supabase | 사용자·저장 상품 저장 | PostgreSQL 기반 DB·인증 | 무료(플랜) | DB |

## 9. 비기능 요구사항

| 항목 | 기준 |
| --- | --- |
| 응답 속도 | 바코드 인식 → 결과 표시까지 8~10초 이내, 단계별 로딩 표시 |
| 지원 환경 | RN 네이티브 디코더(iOS Vision / Android ML Kit) |
| 언어 | UI 한국어, 상품 원문(일본어) + AI 한국어 번역 병행 표시 |
| 보안 | 외부 API Key는 백엔드 환경변수 관리, 클라이언트 노출 금지 |
| 데이터 | 사용자 데이터는 Supabase 저장, 사용자별 접근 제어(RLS) 적용 |
| 개인정보 | 개인정보 처리방침 고지, 사용자 데이터·계정 삭제 기능 제공 |
| 캐시 | 동일 바코드 조회 결과 캐싱으로 API 한도 대응 |
| 오프라인 | 네트워크 미연결 시 스캔 비활성화 및 안내 표시, 연결 복구 시 재개 |
