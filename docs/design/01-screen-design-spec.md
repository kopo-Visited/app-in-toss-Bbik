## 1. 화면 목록

| No | 화면명 | 화면 ID | 관련 기능 | 설명 |
| --- | --- | --- | --- | --- |
| S-1 | 로그인 | login | F-001 | 토스 로그인으로 앱 진입 |
| S-2 | 메인(홈) | home | F-002 | 스캔 시작·저장 목록 진입 |
| S-3 | 바코드 스캔 | scan | F-002 | 카메라로 바코드 인식 |
| S-3a | 바코드 직접 입력 | manual-input | F-002 | 바코드 숫자를 직접 입력 |
| S-4 | 상품 촬영 | capture | F-003 | 조회 실패 시 상품 전면 촬영 |
| S-5 | 결과 | result | F-003 | 상품 정보(번역) 표시·저장·공유 |
| S-6 | 저장 목록 | saved | F-005 | 저장한 상품 목록 조회·삭제 |

> 로딩·토스트·에러는 별도 화면이 아니라 각 화면 내 상태로 처리한다. (5. 상태 화면 참고)

## 2. 화면 흐름

```
[S-1 로그인]
   │ 토스 로그인 성공
   ▼
[S-2 메인] ───────────────────────────▶ [S-6 저장 목록]
   │ 스캔하기                                │ 항목 탭 → S-5 결과
   ▼                                         │ 왼쪽 스와이프 → 삭제
[S-3 바코드 스캔] ──직접입력──▶ [S-3a 직접 입력]
   │ 바코드 인식                              │ 숫자 입력 → 조회
   ▼                                         │
 조회 (백엔드) ◀───────────────────────────┘
   │
   ├─ 성공 ─────────────────▶ [S-5 결과] (barcode)
   │                              │ 저장 / 공유
   └─ 실패 ─▶ [S-4 상품 촬영]      └─▶ (S-2 또는 S-6)
                  │ 촬영 → 재조회
                  ├─ 성공 ─▶ [S-5 결과] (keyword)
                  └─ 실패 ─▶ [S-5 결과] (ai, 참고 정보)
```

## 3. 화면별 상세

### S-1. 로그인 화면 (login)

| 항목 | 내용 |
| --- | --- |
| 관련 기능 | F-001 토스 로그인 |
| 목적 | 토스 계정으로 앱에 진입 |
| 진입 경로 | 앱 최초 실행 |
| 배경 | 흰색 (라이트) |

**구성 요소**

| 요소 | 설명 |
| --- | --- |
| 앱 로고 / 이름 | 삑(Bbik) 로고 + 앱 이름 |
| 서비스 설명 | "일본 상품 바코드를 스캔하면 한국어로 알려드려요" |
| 토스로 시작하기 버튼 | 탭하면 토스 SDK 인증 시작 (파란색 메인 버튼) |
| 보조 안내 | "토스 계정으로 간편하게 시작해요" |

**동작**

- "토스로 시작하기" 탭 → 토스 인증(토스 SDK가 띄움) → 성공 시 S-2 메인으로 이동
- 이미 로그인된 사용자는 이 화면을 건너뛰고 바로 S-2로 진입

**예외 표시**

- 토스 앱 미설치: 설치 안내
- 네트워크 오류: "네트워크를 확인해주세요" (S-5 에러 상태 참고)

---

### S-2. 메인(홈) 화면 (home)

| 항목 | 내용 |
| --- | --- |
| 관련 기능 | F-002 (스캔 진입), F-005 (저장 목록 진입) |
| 목적 | 스캔 시작과 저장 목록 진입의 허브 |
| 진입 경로 | 로그인 성공 후 |
| 배경 | 흰색 |

**구성 요소**

| 요소 | 설명 |
| --- | --- |
| 상단 인사 | "안녕하세요" / "무엇을 스캔해볼까요?" |
| 바코드 아이콘 | 화면 중앙 일러스트 (파란 바코드) |
| 안내 문구 | "일본 상품 바코드를 찍어보세요" |
| 스캔하기 버튼 | 메인 버튼(파란색). 탭하면 S-3 스캔으로 |
| 저장 목록 버튼 | 보조 버튼(연한 파란색). 탭하면 S-6으로 |

**동작**

- 스캔하기 탭 → S-3 바코드 스캔
- 저장 목록 탭 → S-6 저장 목록

---

### S-3. 바코드 스캔 화면 (scan)

| 항목 | 내용 |
| --- | --- |
| 관련 기능 | F-002 바코드 스캔 |
| 목적 | 카메라로 상품 바코드(JAN/EAN) 인식 |
| 진입 경로 | S-2에서 스캔하기 |
| 배경 | 어두운색 (카메라 영상) |

**구성 요소**

| 요소 | 설명 |
| --- | --- |
| 카메라 화면 | 후면 카메라 실시간 영상 |
| 스캔 가이드 프레임 | 바코드를 맞추는 흰색 사각 가이드 |
| 안내 문구 | "바코드를 사각형 안에 맞춰주세요" |
| 바코드 직접 입력하기 버튼 | 인식 안 될 때 S-3a로 전환 |
| 닫기(X) | S-2로 복귀 |

**동작**

- 바코드 인식 성공 → 자동 조회 시작 → 로딩 표시 → 결과(S-5) 또는 촬영(S-4)
- 일정 시간 미인식 → "직접 입력" 유도 (안내 팝업)
- "바코드 직접 입력하기" 탭 → S-3a

**예외 표시**

- 카메라 권한 거부: 권한 안내 후 설정 이동 유도
- 지원하지 않는 바코드: "인식할 수 없는 바코드입니다" 안내

**처리 중 상태(로딩)**

- 조회 진행 중: "상품 정보를 불러오는 중..." 로딩 표시 (최대 8~10초)

### S-3a. 바코드 직접 입력 화면 (manual-input)

| 항목 | 내용 |
| --- | --- |
| 관련 기능 | F-002 (바코드 인식 폴백) |
| 목적 | 카메라 인식이 안 될 때 바코드 숫자를 손으로 입력 |
| 진입 경로 | S-3에서 "바코드 직접 입력하기" |
| 배경 | 흰색 |

**구성 요소**

| 요소 | 설명 |
| --- | --- |
| 제목 | "바코드 직접 입력" |
| 안내 | "상품 바코드 숫자를 입력해주세요 (EAN-13 또는 EAN-8)" |
| 입력칸 | 숫자 입력 (밑줄 스타일), "13자리 숫자" 안내 |
| 조회하기 버튼 | 입력한 바코드로 조회 (파란색) |
| 뒤로 | S-3으로 복귀 |

**동작**

- 숫자 입력 → "조회하기" 탭 → 입력한 JAN으로 조회 → 로딩 → 결과(S-5) 또는 촬영(S-4)

### S-4. 상품 촬영 화면 (capture)

| 항목 | 내용 |
| --- | --- |
| 관련 기능 | F-003 (조회 실패 시 폴백) |
| 목적 | 라쿠텐 조회 실패 시 상품 전면을 촬영해 재조회 |
| 진입 경로 | S-3 / S-3a 조회 실패 |
| 배경 | 어두운색 (카메라 영상) |

**구성 요소**

| 요소 | 설명 |
| --- | --- |
| 카메라 화면 | 상품 전면 촬영용 |
| 촬영 가이드 | 상품을 맞추는 점선 사각 틀 |
| 안내 문구 | "상품명과 브랜드명이 잘 보이게 찍어주세요" |
| 촬영 버튼 | 동그란 셔터 버튼 |
| 뒤로 | 이전 화면으로 |

**동작**

- 촬영 → 이미지를 백엔드로 전송 → 상품명 추출 → 라쿠텐 재조회
- 재조회 성공 → S-5 결과 (lookupType: keyword)
- 재조회 실패 → AI 판단 결과 → S-5 결과 (lookupType: ai)

**예외 표시**

- 상품명 추출 실패: "상품명이 잘 보이게 다시 촬영해주세요" + 다시 찍기
- (S-5 조회 실패 상태 참고)

**처리 중 상태(로딩)**

- 분석 중: "상품을 분석하는 중..." 로딩 표시

### S-5. 결과 화면 (result) ★핵심

| 항목 | 내용 |
| --- | --- |
| 관련 기능 | F-003 (결과 표시), F-004 (저장), F-006 (공유) |
| 목적 | 조회·번역된 상품 정보를 보여주고 저장·공유 |
| 진입 경로 | S-3/S-3a/S-4 조회 성공, 또는 S-6 목록에서 항목 탭 |
| 배경 | 흰색 |

**구성 요소**

| 요소 | 설명 |
| --- | --- |
| 상품 이미지 | 라쿠텐 이미지 또는 촬영 이미지 (없으면 기본 이미지) |
| 상품명 (한국어) | 번역된 상품명 — 가장 크게 강조 |
| 상품명 (일본어) | 원문 상품명 |
| 브랜드명 (한/일) | 브랜드명 태그 (있을 때만) |
| 가격 | "라쿠텐 참고가" + "약 ¥{가격}". 없으면 "가격 정보 없음" |
| AI 안내 박스 (선택) | lookupType=ai인 경우만 표시 (아래 상태별 표시) |
| 공유 버튼 | 공유 문구 복사 / 외부 공유 (F-006) |
| 저장 버튼 | 저장 목록에 추가 (F-004, 파란색 메인 버튼) |
| 뒤로/닫기 | 메인 또는 이전 화면으로 |

**동작**

- 저장 탭 → "저장되었습니다" 토스트. 이미 저장된 상품이면 "이미 저장된 상품입니다"
- 공유 탭 → 공유 문구 생성 → 클립보드 복사 또는 공유 시트
- 가격: 값 있으면 "약 ¥{가격}", null 또는 0이면 "가격 정보 없음"

**상태별 표시 (lookupType 3종)**

| lookupType | 의미 | 화면 차이 |
| --- | --- | --- |
| barcode | 바코드 조회 성공 | 일반 표시 (상품명·브랜드·가격·이미지) |
| keyword | 사진→키워드 재조회 성공 | 일반 표시 (barcode와 동일) |
| ai | 라쿠텐 실패 → AI 판단 | 노란 안내 박스 추가: "AI 분석 기반 참고 정보예요. 실제와 다를 수 있어요." + 가격은 보통 "가격 정보 없음" |

---

### S-6. 저장 목록 화면 (saved)

| 항목 | 내용 |
| --- | --- |
| 관련 기능 | F-005 저장 목록 조회·삭제 |
| 목적 | 저장한 상품을 모아 보고 관리 |
| 진입 경로 | S-2 저장 목록 버튼 |
| 배경 | 흰색 |

**구성 요소**

| 요소 | 설명 |
| --- | --- |
| 타이틀 | "OO님의 저장한 상품" |
| 전체 삭제 버튼 | 상단 우측. 저장된 상품이 1개 이상일 때만 노출 |
| 상품 리스트 | 저장 상품들을 리스트로 (최근순) |
| 리스트 항목 | 썸네일 이미지 + 상품명(한) + 가격 |
| 삭제 (스와이프) | 항목을 왼쪽으로 밀면 빨간 "삭제" 버튼 노출 (개별 삭제) |
| 빈 상태 | "저장한 상품이 없어요" + "스캔하러 가기" 버튼 |
| 뒤로 | S-2로 복귀 |

**동작**

- 항목 탭 → S-5 결과 화면(저장된 상품 상세)
- 왼쪽 스와이프 → "삭제" 버튼 노출 → 탭하면 해당 항목만 제거 (개별 삭제)
- 전체 삭제 탭 → "저장한 상품을 모두 삭제할까요?" 확인 팝업 → 확인 시 전체 삭제 → 빈 상태로 전환
- 빈 상태에서 "스캔하러 가기" → S-3

> 전체 삭제는 실수 방지를 위해 반드시 확인 팝업을 거친다. (다크패턴 금지 규칙 준수)

## 5. 상태 화면 (별도 페이지 아닌 상태)

각 화면 내에서 나타나는 상태들. 발표 시연을 위해 디자인 정의함.

| 상태 | 표시 내용 | 나타나는 시점 |
| --- | --- | --- |
| 로딩 | 스피너 + "상품 정보를 불러오는 중..." | 스캔/조회 후 결과 나오기 전 |
| 저장 완료 토스트 | 하단 검은 토스트 + "✓ 저장되었습니다" | 결과 화면에서 저장 탭 시 (잠깐 뜸) |
| 조회 실패 | "상품을 찾지 못했어요" + "다시 찍기" | 촬영 분석까지 실패했을 때 |
| 네트워크 에러 | "네트워크를 확인해주세요" + "다시 시도" | 인터넷 연결 불안정 시 |

## 6. 화면 ↔ API 매핑

| 화면 | 호출하는 API |
| --- | --- |
| S-1 로그인 | `POST /api/auth/toss/login` |
| S-3 바코드 스캔 / S-3a 직접 입력 | `GET /api/products/lookup` |
| S-4 상품 촬영 | `POST /api/products/analyze-image` |
| S-5 결과 (저장) | `POST /api/saved-products` |
| S-5 결과 (공유) | `POST /api/share/products` |
| S-6 저장 목록 | `GET /api/saved-products` (목록 조회), `DELETE /api/saved-products/{id}` (개별 삭제), `DELETE /api/saved-products` (전체 삭제) |

> S-2 메인은 별도 API 호출 없이 화면 전환만 담당한다.
